# Notification test plan

Verify these cases on a physical device before release: Discreet ON should show New Activity for all partner activity. Discreet OFF should show only the safe activity label: New Message, New Picture, New Video, New GIF, New Dare, New Wish, or New Activity fallback. Confirm that no notification displays sender name, message or caption text, media preview, Dare or Wish content, or reaction content.
